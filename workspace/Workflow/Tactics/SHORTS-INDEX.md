# Short-form tactics (Shorts / TikTok / Reels)

This is the pick list for the short-form pipeline (the `short-*` skills). Long-form work uses `INDEX.md` instead, and neither pipeline loads the other's list (`STYLE.md`).

A tactic useful in both formats keeps one folder and appears in both lists, marked *(also long-form)* or *(also short-form)*; its `TACTIC.md` says how it applies. The folder layout, statuses and maintenance rules are the same as in `INDEX.md` → "Maintaining the library".

- Examples are reference points, not templates; never reuse another creator's footage, lines or branding.
- Platform facts are dated. Re-check them against the current help pages before relying on them.
