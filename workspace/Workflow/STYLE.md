# Editing preferences

The user's confirmed preferences, shared by every agent that works here. The setup interview (`docs/SETUP.md`) fills in the tables below; rows marked *starter default* came with the kit from its original author. Keep them, change them or delete them. Video-specific feedback lives in each video's `RECORD.md`. Learned technical rules live in `LESSONS.md`. This is file-based memory, not model training.
